# Privacy

The released application is designed to run without accounts, cookies,
analytics, advertising, telemetry, a database, or user-content submission.
Interaction state stays in the current browser tab and is not intentionally
sent to the repository owner.

Hosting providers may independently process ordinary request metadata such as
IP addresses and user-agent strings. Operators should review their provider's
logs and retention settings, disable unnecessary request logging, and publish
an appropriate site-level privacy notice for the chosen deployment.

The application links to external medical and scientific sources. Following a
link sends a request to that external site under its own privacy policy.

Any future analytics, persistence, authentication, feedback form, or API must
be opt-in where required, documented here, and reviewed before release.
